# ig-audit 한국어 가이드 (ko-KR)

먼저 공통 규칙 `../ig-i18n/style-ko-KR.md`(이 스킬 폴더 기준 경로)를 읽습니다.
측정 지표와 순서(배수, 비팔로워 도달, 3초 유지, 평균 시청 시간, 도달 대비 공유, 도달 대비 팔로우)는 영어와 같습니다.

## 지표 이름 (인스타그램 한국어 인사이트 화면과 맞춤)

| 영어 | 한국어 | 계산 |
| --- | --- | --- |
| Outlier multiple | 배수 | 조회수 / 계정의 조회수 중앙값 |
| Non-follower reach | 비팔로워 도달 비율 | 도달 중 팔로워가 아닌 계정 비율 |
| Hold at 3s | 3초 유지율 | 3초에 남은 시청자 / 시작한 시청자 |
| Average watch time | 평균 시청 시간 | 인사이트 그대로 |
| Sends per reach | 도달 대비 공유 | 공유 / 도달 |
| Follows per reach | 도달 대비 팔로우 | 팔로우 / 도달 |

## 한국어에서 달라지는 것

- 숫자는 사용자가 붙여 넣은 그대로 계산합니다. 인사이트 화면의 `1.2만`, `3천`은 12,000, 3,000으로 바꿔 계산하고 표에는 원래 표기를 같이 씁니다.
- 계산 과정을 보여 줍니다. 결론은 근거와 함께 주장으로, 확신 정도와 함께.
- 표본이 6개면 패턴이 아니라고 말합니다. 30개쯤에서 경향을 말합니다.
- 없는 숫자를 채우지 않습니다. 인사이트에 없는 값은 `?`로 둡니다.
- 요일과 시간은 맨 마지막에, 다른 요인이 아무것도 안 보일 때만.

## 출력

```
점검  |  게시물 31개  |  {{기간}}  |  조회수 중앙값 {{중앙값}}

배수 상위 5
  18.2x  #3 아무도 안 알려주는 것  ...
  ...

하위 5
  ...

데이터가 말하는 것
1. 3초 유지율이 전부입니다. 상위 5개 평균 {{값}}, 하위 5개 {{값}}.
2. ...

그만할 것: ...
더 할 것: ...
```

결론은 `/ig-plan`과 `/ig-viral`로 넘깁니다.
