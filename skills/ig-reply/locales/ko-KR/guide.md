# ig-reply 한국어 가이드 (ko-KR)

먼저 공통 규칙 `../ig-i18n/style-ko-KR.md`(이 스킬 폴더 기준 경로)를 읽습니다.
여섯 가지 분류, 분류 순서대로 답하기, 질문은 릴스로 답하기, 악플에는 답하지 않기는 영어와 같습니다.

## 분류 이름

| 영어 | 한국어 | 받는 것 |
| --- | --- | --- |
| KEYWORD | 키워드 | 약속한 것. 손으로 보내거나 승인된 자동화로 |
| LEAD | 잠재 고객 | 공개 답변 먼저, 끝에 한 문장으로 도움 제안 |
| SUBSTANCE | 내용 | 가장 긴 답글 |
| QUESTION | 질문 | 많은 사람이 궁금하면 답글이 아니라 릴스로 |
| SUPPORT | 응원 | 좋아요, 3~8단어 |
| NOISE | 소음 | 무시, 또는 한 줄 |

## 한국어에서 달라지는 것

- 답글은 상대 길이에 맞춥니다. "와 대박"에 네 줄 답은 하지 않습니다.
- 이름(닉네임)은 처음에 한 번, 느낌표 없이: `{{닉네임}}님, ...`
- 키워드 답글이 수십 개면 같은 문장을 복사하지 말고 말끝을 조금씩 다르게. 내용(보내는 것)은 같게.
- 비판에는 맞는 부분을 그 사람의 말로 먼저 인정하고, 그다음 입장을 지킵니다. 한 스레드에 두 번 답하지 않습니다.
- "DM 주세요"로 답을 미루지 않습니다. 답할 수 있는 건 공개 답글에서 답합니다.

## 출력

```
답글  |  댓글 84개  |  키워드 41, 잠재 고객 2, 내용 3, 질문 2, 응원 34, 소음 2

키워드 (41)  프롬프트 전송. 한 줄씩, 같은 온도로, 복사는 하지 않기.

잠재 고객
@handle - "저희 팀도 회의록 담당자가 매번 바뀌어서 고민이에요"
> 담당자를 정하기보다 녹음 파일을 올리는 사람만 정해 두면 정리는 자동으로 됩니다. 필요하시면 쓰는 프롬프트 보내 드릴게요.

질문 -> 릴스
@handle - "화상 회의 녹음도 되나요?"
  같은 질문이 여러 번 보입니다. 답글이 아니라 릴스로, #16 질문 그대로.

소음 (2)  넘어감. 답하면 그 사람에게 도달을 줍니다.
```

사용자가 "응"이라고 하기 전에는 아무것도 올리지 않습니다.
