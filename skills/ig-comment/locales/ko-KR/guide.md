# ig-comment 한국어 가이드 (ko-KR)

먼저 공통 규칙 `../ig-i18n/style-ko-KR.md`(이 스킬 폴더 기준 경로)를 읽습니다.
아홉 가지 댓글 유형, 한두 문장, 한 가지 생각, 홍보 금지, 자동 게시 금지는 영어와 같습니다.

## 유형 이름

| # | 한국어 | 모양 |
| --- | --- | --- |
| 1 | 근거 보태기 | "저희도 비슷했는데, ..."처럼 실제 숫자나 사실 하나 (사용자가 준 것만) |
| 2 | 빠진 경우 | "이건 ~할 때까지는 맞는 것 같아요." |
| 3 | 정중한 반대 | 동의하는 부분 먼저, 그다음 갈리는 지점 |
| 4 | 한 줄 이어 쓰기 | 좋은 문장 하나를 짚고 덧붙이기 |
| 5 | 진짜 질문 | 게시물이 건너뛴 어려운 부분을 하나만 |
| 6 | 해 본 사람 | 같은 걸 해 본 결과 두 문장 (사용자의 실제 경험만) |
| 7 | 바로잡기 | 사실 오류. 확실할 때만, 짧고 친절하게 |
| 8 | 다르게 보기 | "다르게 보면 ~" |
| 9 | 한 줄 | 10단어 안팎, 웃기거나 맞는 말 |

## 한국어에서 달라지는 것

- 존댓말이 기본입니다. 상대가 반말 계정이고 사용자가 평소 반말을 쓰는 경우만 예외.
- 쓰지 않는 시작: "좋은 글 감사합니다", "공감합니다", "와 대박", "저장하고 갑니다", "꿀팁 감사해요",
  이모지만, 상대 이름 + 느낌표. 전부 안 읽힙니다.
- 이모지로 시작하지 않습니다. "ㅋㅋ"는 사용자가 평소 쓰는 경우에만, 끝에 한 번.
- 해 본 사람(6)과 근거 보태기(1)는 사용자가 실제로 준 경험과 숫자로만 씁니다. 없으면 다른 유형을 고릅니다.
- 댓글은 좁은 칸에서 읽힙니다. 두 문장, 넘어도 세 문장.

## 출력

```
댓글 후보  (@계정의 회의록 자동화 릴스)

[5 진짜 질문]
녹음 앞부분에서 이름을 불러 두는 방법, 화상 회의에서도 그대로 되나요? 참석자가 많을 때가 궁금해요.

[3 정중한 반대]
표로 뽑는 건 좋은데, 결정 안 된 안건까지 표에 들어가면 오히려 헷갈릴 것 같아요. 미정 항목은 따로 빼는 게 낫지 않을까요?

첫 번째를 추천합니다. 구체적이고, 이 영상에서만 나올 수 있는 질문입니다.
```

"~더라고요", "저희도 해 봤는데"처럼 겪은 일로 쓰는 말투는 사용자가 실제로 겪은 일일 때만 씁니다.
