# ig-repurpose 한국어 가이드 (ko-KR)

먼저 공통 규칙 `../ig-i18n/style-ko-KR.md`(이 스킬 폴더 기준 경로)를 읽습니다.
요약하지 말고 뽑아내기, 형식 고르기, 각 게시물은 원본 없이도 서야 한다는 원칙은 영어와 같습니다.

## 한국어에서 달라지는 것

- 뽑아낼 것의 한국어 이름: 주장, 숫자, 이야기, 원리, 실수, 그대로 쓸 문장. 개수를 먼저 보여 줍니다.
- 원본이 영어(영어 영상, 영어 뉴스레터)여도 결과는 한국어로 **다시 씁니다**. 번역하지 않습니다.
  인용이 필요하면 원문은 짧게, 출처는 캡션에만.
- 원본이 사용자의 한국어 영상이면 실제 그 장면을 씁니다. 자막은 말한 그대로 받아 적고, 군말(어, 음, 그러니까)만 뺍니다.
- "지난 영상에서 말씀드린 것처럼"은 쓰지 않습니다. 보는 사람은 원본을 본 적이 없습니다.
- 다섯 개를 뽑으면 훅 공식을 다섯 개 다르게. 같은 모양이 반복되면 공장 같아 보입니다.
- 원본에 없는 숫자, 결과, 사례를 보태지 않습니다.

## 출력

```
원본: "{{제목}}" ({{길이}} 팟캐스트)

찾은 것  주장 5, 숫자 9, 이야기 3, 원리 4, 실수 2, 그대로 쓸 문장 7

이번 주
화  릴스     #2 금지 명령      회의록 손으로 쓰지 마세요       14:20 장면, 끝에 웃음
수  캐러셀   Job B 캡션        녹음부터 표까지 4단계
금  릴스     #21 중간부터 시작  "...그래서 {{원본의 그 장면}}"
일  릴스     #5 시간 단축       {{원본에 나온 시간}}

"화요일 써 줘"라고 하시면 초안을 씁니다.
```

초안은 하나씩, 각각 `/ig-reel --locale ko-KR`과 `/ig-human --locale ko-KR`을 거칩니다.
