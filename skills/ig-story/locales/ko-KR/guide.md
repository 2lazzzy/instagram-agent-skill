# ig-story 한국어 가이드 (ko-KR)

먼저 공통 규칙 `../ig-i18n/style-ko-KR.md`(이 스킬 폴더 기준 경로)를 읽습니다.
하루 3~7장, 4번째 장에 요청, 스티커별 역할, "상대가 먼저 움직인다"는 DM 원칙은 영어와 같습니다.

## 한국어에서 달라지는 것

- 스토리는 팔로워에게 하는 말이라 피드보다 말투가 가깝습니다. 사용자의 평소 말투(해요체, 반말 여부)를
  `voice.md`에서 확인하고 그대로 씁니다.
- 한 장에 한 문장, 20자 안팎. 화면 위아래 안전 영역(1080x1920에서 y=250 위, y=1600 아래)은 영어와 같습니다.
- 스티커 문구도 한국어로 짧게:
  - 투표: "회의록, 손으로 정리하세요?"  `네` / `이제 안 해요`
  - 질문: "자동화하고 싶은 일 하나만 적어 주세요"
  - 퀴즈: 흔한 오해 하나를 고르게
- 질문 상자에 들어온 답은 사용자의 말 그대로 모아 `/ig-reel`에 #16(질문 그대로)으로 넘깁니다.
- 한국어 스토리에서 자주 보이는 "좋아요 눌러 주세요", "공유 부탁드려요"는 요청 하나로 줄입니다.

## 출력

```
스토리  |  화요일  |  5장

1  [화면 녹화]       "회의 끝나고 할 일, 이렇게 정리합니다"
2  [녹음 파일 업로드] 표가 만들어지는 장면
3  [얼굴]            "담당자 이름은 녹음 앞부분에 한 번씩 불러 두세요"
4  [투표]            "회의록, 아직 손으로 정리하세요?"  네 / 이제 안 해요
5  [사진 위 글자]     "'네'에 투표하신 분께 프롬프트 보내 드릴게요"

이후: '네'에 투표한 사람에게 한 명씩 답장합니다. 그게 퍼널 전부입니다.
```

게시는 하지 않습니다.
