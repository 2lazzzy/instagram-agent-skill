# 한국어 콘텐츠 공통 규칙 (ko-KR)

모든 스킬이 ko-KR로 실행될 때 이 파일을 먼저 읽습니다. 스킬별 규칙은 각 스킬의
`locales/ko-KR/guide.md`에 있고, 둘이 부딪히면 스킬별 규칙이 이깁니다. 사용자의
`voice.md`는 둘 다보다 우선합니다.

## 1. 번역하지 말고 처음부터 한국어로 쓴다

- 영어 SKILL.md의 예시 문장, 출력 라벨, 영수증 블록을 그대로 옮기지 않습니다.
  출력은 라벨까지 전부 한국어입니다 (`REEL READY` 대신 `릴스 준비 완료`).
- 영어 구조를 직역한 문장은 고칩니다.
  - "당신은 ~하고 있습니까?" 대신 "~하고 계신가요?" 또는 주어를 뺀 문장.
  - "A, B, 그리고 C" 대신 "A, B, C" 또는 "A와 B, C".
  - "~에 있어서", "~함에 있어", "~하는 것이 가능합니다" 대신 "~에서", "~할 때", "~할 수 있습니다".
  - "그것은", "그들은" 같은 대명사 주어는 대부분 뺍니다.
- 한국어는 서술어가 끝에 옵니다. 훅과 첫 줄에서는 핵심어(숫자, 이름, 손해)를 앞쪽 어절로 끌어옵니다.

## 2. 문장 길이와 리듬

- 한 문장에 한 가지만. 한 문장이 휴대폰 화면에서 세 줄을 넘으면 나눕니다.
- 같은 어미, 같은 마지막 단어가 연달아 나오지 않게 합니다. 질문, 짧은 명사문,
  다른 동사로 끝나는 문장을 섞습니다. 존댓말 수준(합니다체, 해요체)은 바꾸지 않습니다.
- 문장 첫머리 연결어(또한, 더불어, 이를 통해, 따라서)는 꼭 필요할 때만.
- 릴스 대본은 소리 내어 읽어서 숨이 차지 않는 길이로 끊습니다.

## 3. 과장하지 않는다

- 쓰지 않는 말: 충격, 역대급, 미쳤다, 무조건, 인생이 바뀌는, 모르면 손해, 끝판왕,
  치트키, 혁신적인, 게임 체인저, 차원이 다른. 대신 무엇이 얼마나 달라지는지를 씁니다.
- 클릭베이트는 한 번은 통해도 팔로우로 이어지지 않습니다. 훅은 약속이고, 영상은 그 약속을 지켜야 합니다.

## 4. 지어내지 않는다

- 조회수, 매출, 수익, 시간 절약 수치, 고객 사례, 1인칭 경험("써 보니까", "제가 해 보니")을
  만들어 내지 않습니다. 사용자가 준 사실과 `voice.md`의 "쓸 수 있는 증거"만 씁니다.
- 숫자가 필요한데 없으면 `{{내 숫자}}`, `{{걸린 시간}}`처럼 비워 두고 표시합니다. 예시를 쓸 때도 같습니다.
- 통계는 출처를 말할 수 있을 때만 씁니다.

## 5. 표기

- 가운뎃점(·)과 줄표(—)는 쓰지 않습니다. 쉼표, 콜론, 괄호를 씁니다. (3·1절 같은 고유 표기는 예외)
- 숫자는 아라비아 숫자와 한국어 단위로: 1만 2천 원, 3시간, 5분, 30%. 큰 수는 '만' 단위로 끊습니다.
- 영어 제품명은 원래 표기 그대로(Claude, Notion, ChatGPT). 한글 표기가 더 익숙한 이름은 한글로(노션, 엑셀).
- 해시태그는 띄어쓰기 없이 한글 그대로: `#업무자동화`, `#회의록`. 최대 5개.
- 이모지는 문장부호처럼 가끔만. 글머리표로 쓰지 않습니다.

## 6. 톤은 주제와 사용자가 정한다

- `voice.md`의 존댓말 수준, 자주 쓰는 말, 절대 안 쓰는 말이 최우선입니다. 비어 있으면
  사용자의 기존 글 세 개를 받아 추론합니다.
- 주제별 기본값(사용자 설정이 없을 때만):
  - 개발, AI 도구: 정확한 용어, 짧은 문장, 과장 없음. 명령어와 기능 이름을 그대로.
  - 생산성, 일상 자동화: 상황 하나로 시작해서 바로 방법으로. 해요체가 자연스럽습니다.
  - 뉴스, 업데이트: 무엇이 바뀌었는지, 누구에게 해당하는지, 언제부터인지.
- 같은 사람의 글이 매번 다른 사람처럼 들리면 안 됩니다. 브랜드 톤이 규칙보다 우선입니다.

## 7. 점수에 대해 정직하게 말한다

- `hookscore.py`, `detect.py`의 점수는 텍스트만 보고 계산한 휴리스틱입니다. 조회수나
  바이럴 확률이 아니고, 한국어 기준값은 한국어 성과 데이터로 검증되지 않았습니다.
  사용자에게 점수를 보여 줄 때 이 점을 한 줄로 말합니다.
- `beats.py`의 한국어 시간은 음절 기반 추정치입니다. 실제 녹음 길이로 `--calibrate` 하기 전까지는 추정이라고 밝힙니다.
