# ig-help 한국어 안내

공통 규칙은 `../../../ig-i18n/style-ko-KR.md`를 따릅니다. 이 파일은 도움말의
표현과 예시를 정합니다. 설치된 스킬 확인과 요청 분류는 `../../SKILL.md`를 따릅니다.
도움말을 읽으려고 브랜드 정보나 기존 글을 제출하게 하지 않습니다. 기본 해요체로
바로 답하고, 명령어 이름을 제외한 표 제목과 설명은 한국어로 씁니다.

## 전체 목록

`/ig-help`만 입력하면 확인된 스킬 수와 아래 표를 보여 줍니다. 표의 목록은 설명의
기준이며 실제 목록은 같은 묶음에 설치된 `SKILL.md`로 확인합니다. 없는 스킬은
설치된 목록에서 제외하고, 새 스킬은 해당 파일의 설명으로 보충합니다. 확인할 수
없으면 문서상 목록이며 설치 여부는 확인하지 못했다고 짧게 밝힙니다.

| 명령어 | 언제 쓰고 무엇을 받는지 | 준비할 것 |
| --- | --- | --- |
| `/ig-help` | 관련 스킬 목록, 역할, 제작 순서를 확인해요 | 없어도 돼요. 주제나 스킬 이름으로 좁힐 수 있어요 |
| `/ig-profile` | 프로필을 점검하고 소개글, 링크, 하이라이트 등의 개선안을 받아요 | 프로필 내용이나 화면, 계정 목표 |
| `/ig-viral` | 참고할 게시물을 조사하고 근거가 있는 사례를 모아요 | 분야, 타깃, 참고 계정이나 게시물 |
| `/ig-plan` | 이번 주에 어떤 주제를 어떤 형식으로 올릴지 정해요 | 목표, 타깃, 주제, 실제 경험이나 소재 |
| `/ig-repurpose` | 기존 자료에서 소재를 뽑아 릴스나 캐러셀로 풀어내요 | 글, 녹취록, 메모 등 원본 자료 |
| `/ig-reel` | 훅 후보, 말할 대본, 화면 문구, 구간별 시간표를 만들어요 | 주제, 타깃, 확인된 사실, 원하는 길이 |
| `/ig-carousel` | 장별 문구와 배치를 만들고, 문구 승인 후 사용 가능한 도구로 렌더링해요 | 주제, 타깃, 사실, 전달할 핵심 |
| `/ig-human` | 초안의 반복 표현과 어색한 문장을 점검하고 다듬어요 | 다듬을 글, 원하는 말투 |
| `/ig-caption` | 게시물 아래 설명글의 첫 줄, 본문, 행동 유도 문구, 해시태그를 만들어요 | 대본이나 슬라이드 문구, 목표, 키워드 |
| `/ig-story` | 스토리의 장면 순서, 문구, 참여 유도 구성을 만들어요 | 메시지, 목표, 활용할 소재 |
| `/ig-comment` | 다른 사람의 게시물에 남길 댓글을 써요 | 상대 게시물, 내가 보탤 경험이나 의견 |
| `/ig-reply` | 내 게시물에 달린 댓글의 답글을 써요 | 내 게시물, 받은 댓글, 원하는 말투 |
| `/ig-dm` | 문의, 자료 전달, 협업 등의 DM 초안을 써요 | 대화 내용이나 상황, 상대와의 관계, 목적 |
| `/ig-audit` | 게시물 성과를 돌아보고 다음에 바꿀 점을 찾아요 | 게시물 기록, 목표, 확보한 인사이트 지표 |

전체 목록 뒤에는 릴스와 캐러셀의 기본 순서, 사용 예시를 최대 3개 보여 줍니다.
명령어 외의 영어 라벨이나 장황한 소개는 넣지 않습니다.

## 제작 순서를 물었을 때

- 릴스: `/ig-reel`로 훅과 대본 구성 → `/ig-human`으로 표현 점검 →
  `/ig-caption`으로 게시물 설명글 작성.
- 피드 캐러셀: `/ig-carousel`로 장별 문구와 구성 → `/ig-human`으로 표현 점검 →
  `/ig-caption`으로 게시물 설명글 작성. 문구 승인 후 가능한 도구로 시각화해요.

이 순서는 작업 단계입니다. 릴스 스킬은 문장 점검을 포함하고, 캡션은 다음 작업인
`/ig-caption`으로 안내합니다. 캐러셀 스킬은 캡션 작성과 문장 점검까지 포함합니다.
따라서 이미 포함된 문장 점검을 별도로 반복 실행하라고 안내하지 않습니다. 기존
초안을 다듬을 때는 `/ig-human`, 설명글만 만들거나 고칠 때는 `/ig-caption`을
따로 쓰면 됩니다.

소재가 없으면 `/ig-plan`, 참고 사례가 필요하면 `/ig-viral`, 기존 글을 활용하려면
`/ig-repurpose`를 먼저 추천합니다. 게시 후에는 필요에 따라 `/ig-story`,
`/ig-reply`, 성과 자료가 쌓인 뒤 `/ig-audit`을 안내합니다. 요청과 관계있는 것만
몇 개 고르고 전체 목록을 반복하지 않습니다.

## 특정 스킬을 물었을 때

예를 들어 `/ig-help ig-caption`이면 실제 `ig-caption/SKILL.md`와 한국어 가이드를
읽고, 하는 일, 필요한 입력, 결과물, 실행 예시 하나를 알려 줍니다. 필요한 입력과
있으면 좋은 정보를 구분합니다. 없는 스킬 이름에는 일치하는 스킬이 없다고 밝히고
비슷한 선택지를 최대 3개 제안합니다.

예시 입력:

```text
/ig-help 릴스
/ig-help 캐러셀
/ig-help ig-caption
```

특정 스킬의 실행 예시에는 필요한 자료를 자리표시자로 둡니다.

```text
/ig-caption --locale ko-KR 아래 릴스 대본에 맞는 설명글을 써 줘. 목표는 저장이야. [대본 붙여넣기]
```

사용자가 `/instagram-agent:ig-help`로 불렀으면 예시에서도 같은 접두어를 유지합니다.
그 외에는 짧은 명령어를 쓰고, 플러그인 설치 시 접두어가 붙을 수 있다고 한 번만
설명합니다.

## 결과물의 범위

`ig-caption`의 캡션은 게시물 아래 설명글이고, 영상 안의 자막 문구는 릴스 작업에
포함됩니다. `ig-reel`이 주는 것은 제작용 대본과 구성입니다. 촬영과 영상 편집은
별도로 진행합니다. 캐러셀의 렌더링은 사용 가능한 제작 도구가 있을 때 가능합니다.
계획은 예약 게시가 아니며 댓글과 DM은 보내기 전 초안입니다.

`ig-human`은 문장을 점검하는 도구이며 작성자가 사람인지 증명하지 않습니다. 짧은
글은 점수 판정을 보류할 수 있습니다. 조사나 문장 점수가 조회수를 보장하지도
않습니다. 관련 스킬을 설명할 때 필요한 범위에서만 이 차이를 짚습니다.

도움말 자체는 파일을 읽고 사용법을 안내합니다. 사용자가 도움말만 요청했는데 다른
스킬을 실행하거나 콘텐츠, 설정 파일, 게시물, 메시지를 만들거나 보내지 않습니다.
