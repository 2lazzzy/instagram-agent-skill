# ig-profile 한국어 가이드 (ko-KR)

먼저 공통 규칙 `../ig-i18n/style-ko-KR.md`(이 스킬 폴더 기준 경로)를 읽습니다.
채점 기준은 `rubric.json` 그대로(12개 항목, 100점)이고 점수표와 고친 문구만 한국어로 씁니다.

## 항목 이름 (점수표에 쓰는 한국어)

| id | 한국어 |
| --- | --- |
| name_field | 이름 칸 |
| bio_first_line | 소개 첫 줄 |
| bio_body | 소개 나머지 |
| pinned_three | 고정 게시물 3개 |
| link | 링크 |
| highlights | 하이라이트 |
| grid_legibility | 그리드 가독성 |
| photo | 프로필 사진 |
| handle | 사용자 이름(핸들) |
| category_contact | 카테고리와 연락 버튼 |
| recent_activity | 최근 활동 |
| story_presence | 스토리 |

## 한국어에서 달라지는 것

- **이름 칸(30자)**: 검색은 이 칸을 봅니다. 사람들이 실제로 검색하는 한국어 단어로:
  `{이름} | 업무 자동화`, `{이름} | 개발자 생산성`. 한글은 폭이 넓어 30자 안에서도 화면에서 잘릴 수 있으니
  핵심어를 앞에 둡니다. 세 가지 안을 줍니다.
- **소개(150자)**: 누구를 위한 계정이고 무엇이 달라지는지. 직함 나열, 세로 막대(|) 나열, 이모지 세 개 나열은 감점.
  가운뎃점으로 나열하지 않습니다.
- **하이라이트 이름**: 한국어로 짧게. `가격`, `후기`, `사용법`, `소개`처럼 구매자가 묻는 질문 단위로.
- 점수는 후하게 주지 않습니다. 처음엔 30~40점대가 보통입니다.
- 고친 문구는 모두 `/ig-human --locale ko-KR`을 거칩니다.
- 수치나 실적을 지어내지 않습니다. 소개에 넣을 증거가 없으면 `{{쓸 수 있는 실적}}`으로 비웁니다.

## 출력

```
프로필 점수  38/100

  이름 칸          2/12   이름만 있고 검색어가 없음
  소개 첫 줄       3/12   직함 세 개와 커피 이모지
  고정 게시물 3개  0/10   고정된 게시물 없음
  하이라이트       2/8    "일상", "기록", "2023"
  ...

고칠 순서 (잃은 점수가 큰 것부터)
1. 이름 칸
   - {이름} | 업무 자동화
   - {이름} | 회의록, 보고서 자동화
   - {이름} | 개발자 생산성 도구
...
```

인스타그램에 직접 저장하지 않습니다. 사용자가 각 칸을 고칩니다.
