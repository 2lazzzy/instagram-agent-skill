# ig-viral 한국어 가이드 (ko-KR)

먼저 공통 규칙 `../ig-i18n/style-ko-KR.md`(이 스킬 폴더 기준 경로)를 읽습니다.
영어 SKILL.md의 원칙(조회수가 아니라 계정 중앙값 대비 배수, 읽기만 하고 긁어 오지 않음,
로그인 대행 금지, 공식을 베끼고 영상은 베끼지 않음)은 그대로입니다.

## 도구

```bash
python3 swipe.py captured.tsv --out ~/.claude/instagram/swipe.md            # 줄마다 훅 언어로 판단
python3 swipe.py captured.tsv --locale ko-KR --out ~/.claude/instagram/swipe.md
```

- 한국어 훅은 `../ig-reel/locales/ko-KR/hooks.json`의 한국어 공식으로 분류하고 한국어 훅 패널로 점수를 냅니다.
  번호는 영어와 같아서 한국어 계정과 영어 계정을 한 파일에 섞어도 공식 번호로 비교할 수 있습니다.
- 조회수는 화면에 보이는 숫자 표기로 적어도 됩니다: `41.2만`, `1.5천`, `3억`, `41.2K`, `1.2M`, `1B`.
  K/M/B는 대소문자를 구분하지 않습니다. `41.2K`는 41,200, `1.2M`은 1,200,000입니다.
  쉼표는 세 자리씩 묶고, 단위 환산 결과는 0 이상의 정수여야 합니다. 음수, 소수 인원수,
  `NaN`, `inf`, 숫자 외 설명이 섞인 값이나 잘못된 쉼표나 소수점은 거부합니다.
  잘못된 숫자가 있는 행은 제외하며 원본 행 번호와 필드, 숫자 형식 오류를 표준 오류에 알립니다.
  선택 항목인 팔로워 수와 중앙값은 비워도 됩니다. 유효한 행이 하나도 없으면 종료 상태는 2입니다.
- `--locale`을 주면 모든 줄을 그 언어로 읽고, 주지 않으면 줄마다 훅의 언어로 읽습니다.
- `--out swipe.md`처럼 파일명만 주면 현재 폴더에 저장합니다. Markdown 보고서도 터미널과 같은
  언어를 쓰며 주 순위와 참고 목록을 구분합니다.

## 순위와 참고 목록

- 양수인 최근 조회수 중앙값이 있는 행만 **주 순위**에 넣습니다. 배수는 조회수 ÷ 최근 중앙값입니다.
- 중앙값이 비어 있거나 0이면 **참고 목록**에 원래 순서대로 남깁니다. 팔로워 수로 중앙값을
  대신하지 않습니다. 참고용 **조회수 / 팔로워 수**는 별도로 표시하고, 팔로워 수도 없거나 0이면
  계산 불가로 표시합니다.
- 참고 행은 상위, 하위 비교, 공식 빈도, 미분류 개수 등 모든 순위 분석에서 제외합니다.
  전부 참고 행이면 훅 목록을 보존하고 최근 중앙값 수집을 안내합니다. 성공 공식을 추론하지 않습니다.
- JSON의 `n`, `accounts`는 전체 유효 표본, `ranked_n`, `ranked_accounts`는 주 순위 표본입니다.
  `reels`에는 주 순위만, `references`에는 참고 행을 넣고 `reference_n`에 그 개수를 기록합니다.
  참고 행의 `baseline`, `outlier`는 null이며 `views_per_follower`는 조회수 / 팔로워 수입니다.
  순위 행이 없으면 `top_formulas`는 빈 목록, 상위, 하위 점수와 길이는 null, `unclassified`는 0입니다.

## 한국어 표본 모으기

- 계정은 사용자와 규모가 10배 이내인 한국어 계정 위주로. 같은 분야 4, 인접 분야 4, 큰 계정 2~4.
- 훅은 말한 그대로(맞춤법이 틀려도) 적습니다. 다듬으면 분류가 틀어집니다.
- YouTube Shorts 자막을 쓸 때는 한국어 자동 자막을 받습니다: `--sub-langs "ko.*"`.
  자동 자막의 띄어쓰기는 틀리는 경우가 많아 훅 길이(어절)가 흔들립니다. 음절 기준 점수는 덜 흔들립니다.

## 보고

- 상위 1/3에서 많이 나온 공식(개수와 함께), 상위와 하위의 구조 차이, 미분류 훅. 세 가지만.
- 한국어 미분류 훅이 많으면 한국어 공식 정규식이 놓친 패턴일 수 있습니다. 직접 읽고, 같은 모양이
  두 번 이상 나오면 `hooks.json`에 추가할 후보로 적습니다.
- 주 순위 표본 수와 참고 행 수, 확신 정도를 한 줄로. 주 순위가 40개 미만이면 "아직 경향일 뿐"이라고 씁니다.
- 훅 점수는 텍스트 휴리스틱입니다. 상위와 하위의 점수 차이가 작아도 이상한 게 아닙니다.

## 출력

```
스와이프  |  릴스 38개  |  계정 7개  |  기준: 계정 중앙값

배수 상위 (3배 이상)
  ...

많이 나온 공식
  #3 아무도 안 알려주는 것   상위 1/3에 5번, 하위에 0번
  ...

미분류 (6)
  ...

내 버전
  #3  "아무도 안 알려주는데, {{내 분야의 불편한 사실}}."
```

`~/.claude/instagram/swipe.md`에 씁니다. 게시, 팔로우, 좋아요, 메시지는 하지 않습니다.
