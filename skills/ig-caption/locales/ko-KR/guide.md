# ig-caption 한국어 가이드 (ko-KR)

먼저 공통 규칙 `../ig-i18n/style-ko-KR.md`(이 스킬 폴더 기준 경로)를 읽습니다.
영어 SKILL.md의 판단(Job A 또는 Job B, 요청 하나, 해시태그 5개 이하, 링크 금지)은 그대로입니다.

## 도구

```bash
python3 caption.py caption.txt --locale ko-KR --keywords "업무 자동화,회의록 정리"
```

- 한글 해시태그(`#업무자동화`)를 인식합니다. 띄어쓰기 없는 한 덩어리만 태그입니다.
- 피드에서 잘리는 지점은 글자 수가 아니라 표시 폭으로 잽니다. 한글과 이모지는 2, 영문과 숫자는 1.
  기본 125(한글 약 62자)는 추정치입니다. 기기마다 다르니 여유를 둡니다(`--truncate`로 변경).
- 첫 줄이 인사, 예고("오늘은 ~에 대해"), "~하신 적 있으신가요?"로 시작하면 주의로 표시합니다.
- 요청은 한국어와 영어를 같이 셉니다(댓글 키워드, DM, 저장, 공유, 팔로우, 프로필 링크, 넘겨 보기, 질문, 댓글 요청).
  같은 종류는 한 번만 셉니다.
- 검색어는 띄어쓰기와 관계없이 찾습니다("업무 자동화" = "업무자동화").
- 빈 줄 없이 긴 덩어리, 휴대폰에서 다섯 줄을 넘는 문단은 주의로 표시합니다.
- 캡션 길이 2,200자와 해시태그 5개는 Instagram의 수치입니다. 바뀌면 `--limit`, `--hashtag-limit`
  또는 `~/.claude/instagram/config.json`의 `platform`으로 바꿉니다. 도구가 임의로 바꾸지 않습니다.

## 쓰기

- 첫 줄: Job A면 요청을 담백하게, Job B면 훅. 한국어 첫 줄은 62자 안팎에서 끝나거나, 궁금한 지점에서 끊깁니다.
  조사나 수식어 중간에서 잘리면 손해입니다.
- 문단은 2~4문장, 사이에 빈 줄. 줄바꿈만 하고 빈 줄이 없으면 한 덩어리로 보입니다.
- 키워드 요청은 한 단어, 띄어쓰기 없이, 영상에서도 말로: `댓글에 '회의록' 남겨 주세요`.
- 검색어는 사람이 실제로 검색하는 말 그대로 본문에 넣습니다. 해시태그 벽이 아니라 문장 안에.
- 해시태그는 주제 태그만. `#좋아요반사`, `#맞팔`, `#소통`, `#일상` 같은 태그는 아무것도 설명하지 않습니다.
- 한국어와 영어가 섞인 캡션은 제품명만 영어로, 나머지는 한국어 문장으로.

## 출력

```
캡션 준비 완료
유형:      A, 릴스가 훅을 맡음
보이는 부분: 폭 125 중 118 사용 (추정)
요청:      하나, 댓글 키워드 '회의록'
해시태그:  3개
검색어:    '업무 자동화' 2번째 문단, '회의록 정리' 첫 줄
검사:      게시 가능 (READY)
```

게시는 하지 않습니다. 사용자가 붙여 넣습니다.

## 예시 (Job A, 릴스 캡션)

```
녹음 파일 하나로 회의록을 정리하는 방법입니다. 프롬프트는 아래에 그대로 적어 뒀어요.

회의를 녹음하고, 파일을 Claude에 올린 다음 이렇게 적습니다.
"결정된 것, 담당자, 마감일만 표로 정리해 줘."

나온 표는 노션 회의 페이지나 슬랙 채널에 그대로 붙이면 됩니다.

업무 자동화 프롬프트 모음이 필요하면 댓글에 '회의록' 남겨 주세요.

#업무자동화 #회의록 #생산성
```
