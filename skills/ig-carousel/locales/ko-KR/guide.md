# ig-carousel 한국어 가이드 (ko-KR)

먼저 공통 규칙 `../ig-i18n/style-ko-KR.md`(이 스킬 폴더 기준 경로)를 읽습니다.
구조(표지, 문제 제기, 한 장에 하나, 요약, 요청 하나)와 1080x1350 규격은 영어와 같습니다.

## 한국어에서 달라지는 것

- **표지 문구**: 영어 '6단어 이하'는 한국어로 두 줄, 줄당 8~10자 안팎. 핵심어를 첫 줄에.
  예: `회의록 정리` / `{{걸린 시간}}이면 끝`. 숫자는 사용자가 준 것만 쓰고, 없으면 이렇게 비워 둡니다.
- **장마다 제목 3~7단어** 대신 **제목 15자 이내, 본문 60자 이내**. 넘으면 두 장으로 나눕니다.
- **글꼴**: 한글은 획이 많아 작으면 뭉개집니다. 본문 36px 이상, 제목 64px 이상을 권합니다.
  웹폰트는 Pretendard, Noto Sans KR처럼 한글 굵기가 여러 개인 서체를 씁니다(프로젝트 디자인 시스템이 있으면 그것).
- **줄바꿈**: 어절 중간에서 끊지 않습니다. HTML은 `word-break: keep-all;`을 넣습니다.
- **번호**: `3/8`처럼 표기합니다. 끝이 보이면 끝까지 넘깁니다.
- **요약 장**: 캡처해서 보내는 장입니다. 문맥 없이 읽혀야 합니다.
- **가운뎃점, 줄표 금지**. 목록은 줄바꿈과 번호로.
- **대체 텍스트**도 한국어로, 표지는 꼭.

## 캡션

캐러셀 캡션은 `/ig-caption --locale ko-KR`의 Job B입니다. 첫 줄이 훅입니다.

## 출력

```
캐러셀  |  8장

1  표지    회의록 정리 자동화
           녹음 파일 하나면 됩니다
2  문제    회의 끝나고 할 일이 안 보이는 이유
3          1단계: 녹음하기
           앞부분에서 참석자 이름을 한 번씩 부르면 담당자가 덜 틀립니다
...
7  요약    네 단계 한 장 정리
8  요청    댓글에 '회의록' 남기면 프롬프트를 보내 드립니다

캡션: Job B, 첫 줄 훅, 요청 하나, 태그 3개
```

문구를 사용자가 승인한 뒤에 파일을 만듭니다. 업로드는 하지 않습니다.
