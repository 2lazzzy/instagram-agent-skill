# ig-reel 한국어 가이드 (ko-KR)

먼저 공통 규칙 `../ig-i18n/style-ko-KR.md`(이 스킬 폴더 기준 경로)를 읽습니다.
영어 SKILL.md의 흐름(훅 3개, 점수, 대본, 시간, 다듬기, 출력, 게시 안 함)은 그대로 따르고,
아래가 한국어에서 달라지는 부분입니다.

## 도구

```bash
python3 hookscore.py hooks.txt --locale ko-KR
python3 beats.py script.txt --locale ko-KR --target 30
python3 beats.py script.txt --locale ko-KR --calibrate 27.4 --save   # 실제 녹음 길이로 속도 보정
```

- 훅 공식은 `locales/ko-KR/hooks.json`을 읽습니다. 번호와 역할은 영어와 같고, 문장은 한국어로
  다시 만든 것입니다. 각 공식의 `adaptation`에 영어와 무엇이 다른지 적혀 있습니다.
- `hookscore.py`는 한국어에서 단어 수가 아니라 말하는 음절 수로 길이를 잽니다. 권장 10~24음절.
  점수는 텍스트 휴리스틱이고 조회수 예측이 아닙니다. 사용자에게 보여 줄 때 한 줄로 밝힙니다.
- `beats.py`는 분당 음절 수(기본 330, 추정치)와 쉼표, 문장 끝의 짧은 쉼으로 시간을 계산합니다.
  숫자는 읽는 소리로(2026 = 이천이십육, 5음절), 영어는 한국어로 읽는 음절로(AI = 에이아이) 셉니다.
  컷 편집으로 쉼을 다 자르는 영상이면 `--pause-scale 0`.
  사용자가 녹음해 본 적이 있으면 `--calibrate`로 보정하라고 권합니다. 보정 전 시간은 추정이라고 말합니다.
- 자막 검사: 한 비트의 자막이 말이 끝나기 전에 다 읽히지 않으면 표시합니다(`--cps`, 기본 초당 12자).
  표시되면 화면 자막을 요약형으로 줄입니다.

## 훅 쓰기

- 말하는 훅과 화면 훅을 따로 씁니다. 화면 훅은 15자 안팎, 한 줄 또는 두 줄.
- 핵심어(숫자, 이름, 손해)를 앞쪽 어절에. 한국어는 부정과 서술어가 끝에 오므로 "~하지 마세요"
  자체는 앞배치 점수에 들어가지 않습니다. 무엇을 하지 말라는지를 맨 앞에 둡니다.
- '당신'은 거의 쓰지 않습니다. "~하고 계신가요?", "~하세요"가 시청자를 부르는 말입니다.
- 인사, "오늘 영상에서는", "알려 드리겠습니다", "스크롤 멈추세요"로 시작하지 않습니다. 도구가 치명적 문제로 표시합니다.
- 과장 표현("충격", "역대급", "무조건")은 감점됩니다.

## 대본 쓰기

- 사용자의 존댓말 수준을 따릅니다(`voice.md`). 없으면 해요체가 기본입니다.
- 한 비트는 한 문장, 4초 이하. 한국어 기준 약 20음절.
- 숫자가 필요한데 사용자가 주지 않았으면 `{{내 숫자}}`로 남기고 표시합니다. 지어내지 않습니다.
- 마지막 비트에 훅의 단어 하나를 다시 넣어 루프를 만듭니다. `beats.py`가 조사를 떼고 비교합니다.

## 화면 텍스트

- 카드당 15자 안팎(영어의 '6단어 이하'에 해당). 한글은 폭이 넓어서 영어보다 적게 들어갑니다.
- 안전 영역은 영어와 같습니다(1080x1920에서 y=230 위, y=1440 아래, 오른쪽 230px 비우기).

## 출력

```
릴스 준비 완료
훅:        #5 시간 단축, 72점 강함 (텍스트 휴리스틱, 조회수 예측 아님)
길이:      약 27.6초, 비트 8개 (분당 330음절, 추정)
화면 텍스트: 카드 6장
다듬기:    자동 수정 2곳, 확인할 표현 0개, 사람 점수 78 통과
캡션:      다음은 /ig-caption

기록하려면 "응" 또는 "yes", 고칠 게 있으면 말씀해 주세요.
```

## 예시

```
/ig-reel --locale ko-KR 회의록 정리를 Claude로 자동화하는 방법
```

```
훅 후보 (점수는 텍스트 휴리스틱)
  72  강함  #5  시간 단축     "회의록 정리에 걸리던 {{예전 시간}}, 이제 {{지금 시간}}이면 끝납니다."
                               화면: {{예전 시간}} → {{지금 시간}}
  64  보통  #2  금지 명령     "회의록 손으로 정리하지 마세요. 녹음 파일 하나면 됩니다."
                               화면: 회의록, 손으로 쓰지 마세요
  41  약함  #26 최상급        "회의록을 정리하는 가장 게으른 방법."
                               화면: 가장 게으른 방법

#5로 갑니다. 시간 두 개만 채워 주시면 점수가 더 오르고(구체성), 화면 한 장으로 읽힙니다.
```

점수는 예시입니다. 실제 점수는 도구를 돌려서 보여 줍니다.
