# 인스타그램 에이전트 스킬 (한국어 안내)

인스타그램 계정을 운영하는 Claude 스킬 13개입니다. 무료, MIT 라이선스, 가입 없음, API 키 없음.
원작은 Jake Schincariol의 [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill)이고,
이 버전은 영어(en-US)에 더해 한국어(ko-KR)로 콘텐츠를 만들고, 분석하고, 검사할 수 있게 고친 것입니다.
English: [README.md](README.md).

**아무것도 대신 올리지 않습니다.** 스킬은 쓰고, 게시는 사용자가 합니다.

## 한국어 지원이 뜻하는 것

문서 번역이 아니라 코드가 한국어를 다르게 다룹니다.

- **훅 공식 26개**를 한국어로 다시 만들었습니다. 번호와 역할은 영어와 같고, 직역이 어색한 공식은
  한국어 어순에 맞게 바꿨습니다(공식마다 `adaptation`에 이유가 있습니다).
- **훅 점수**는 단어 수 대신 말하는 음절 수, 한국어 숫자와 단위(만, 원, 분, 세 가지), 활용형 어간(잃었, 날렸),
  서술어가 끝에 오는 어순, 생략된 주어(존댓말 명령과 질문 어미)를 봅니다.
- **릴스 길이**는 영어 WPM 대신 분당 음절 수로 계산하고, 숫자는 읽는 소리로(2026 = 이천이십육),
  영어는 한국어로 읽는 음절로(AI = 에이아이) 셉니다. 쉼표와 문장 끝의 짧은 쉼, 자막을 읽는 속도도 봅니다.
  기본 속도는 추정치이고, 내 녹음 한 번으로 보정할 수 있습니다.
- **캡션 검사**는 한글 해시태그, 표시 폭 기준 피드 잘림, 한국어 첫 줄(인사, 예고), 한국어와 영어가 섞인 요청,
  이모지 묶음, 띄어쓰기와 무관한 검색어, 긴 문단을 봅니다.
- **AI 문체 검사**는 탐지와 수정을 나눴습니다. 뜻이 바뀌지 않는 것(보이지 않는 문자, 둥근 따옴표, 이중 피동)만
  자동으로 고치고, 과장 표현, 번역투, 상투적 도입과 마무리, 연결어 반복, 같은 말로 끝나는 문장, 가운뎃점(·), 줄표(—)는
  줄 번호와 제안만 보여 줍니다.
- 나머지 9개 스킬은 스킬마다 한국어 가이드(`locales/ko-KR/guide.md`)가 있어서, 한국어로 요청하면 영어 예시가 그대로
  노출되지 않고 한국어 형식으로 답합니다.

## 설치

Claude에 이렇게 붙여 넣거나:

```
https://github.com/Jakeschincariol/instagram-agent-skill

이 스킬을 설치하고 /ig-reel 이 동작하는지 확인해 줘.
```

Claude Code에서 직접:

```bash
git clone https://github.com/Jakeschincariol/instagram-agent-skill.git
cp -r instagram-agent-skill/skills/ig-* ~/.claude/skills/
```

플러그인으로:

```
/plugin marketplace add Jakeschincariol/instagram-agent-skill
/plugin install instagram-agent
```

`skills/ig-i18n` 폴더는 스킬이 아니라 공용 코드입니다(SKILL.md가 없어서 명령으로 보이지 않습니다).
위의 `cp -r skills/ig-*` 명령은 이 폴더도 같이 복사합니다. 스킬 하나만 따로 복사하면 영어는 그대로 동작하고,
한국어는 `ig-i18n`이 옆에 없다는 오류를 냅니다. 플러그인으로 설치하면 플러그인 이름이 붙어
`/instagram-agent:ig-reel`처럼 부를 수도 있습니다.

필요한 것은 Python 3.9 이상뿐입니다. 외부 패키지와 네트워크를 쓰지 않습니다.

## 처음 10분: 내 목소리와 언어 정하기

1. `templates/voice.ko-KR.md`를 `~/.claude/instagram/voice.md`로 복사하고 채웁니다. 맨 위의
   `- **Locale:** ko-KR` 줄 덕분에 모든 스킬이 기본으로 한국어로 씁니다. 직접 채우기 어렵다면 내 릴스나 캡션 세 개를
   Claude에게 주고 "이걸로 voice.md 써 줘"라고 하세요.
2. (선택) `templates/config.example.json`을 `~/.claude/instagram/config.json`으로 복사합니다. 여기의 `locale`이
   `voice.md`보다 우선합니다.
3. (선택) 대본 하나를 녹음해서 실제 길이로 말 속도를 보정합니다.

```bash
python3 ~/.claude/skills/ig-reel/beats.py 내대본.txt --locale ko-KR --calibrate 27.4 --save
```

## 언어 설정 가이드

먼저 걸리는 것이 이깁니다.

| 순서 | 어디서 | 예 |
| --- | --- | --- |
| 1 | 명령의 `--locale` | `/ig-reel --locale ko-KR 회의록 자동화` |
| 2 | 환경 변수 `IG_LOCALE` | `export IG_LOCALE=ko-KR` |
| 3 | `~/.claude/instagram/config.json`의 `"locale"` | `{"locale": "ko-KR"}` |
| 4 | `~/.claude/instagram/voice.md`의 `Locale:` 줄 | `- **Locale:** ko-KR` |
| 5 | 요청이나 글의 언어 | 한글 비율이 30% 이상이면 한국어 |
| 6 | 기본값 | en-US |

- `ko`, `ko-KR`, `ko_kr`, `한국어`, `en`, `en-US` 모두 받습니다. 지원하지 않는 값이면 지원 목록을 보여 주고 종료합니다.
- 아무것도 설정하지 않은 영어 사용자는 영어 글이 영어로 판정되므로 예전과 똑같이 동작합니다.
- 프로필은 한국어인데 분석할 글이 분명히 영어라면, 도구는 프로필을 따르되(설정이 우선) 한 줄 경고를 띄웁니다.
  그럴 땐 `--locale en-US`를 붙이세요.
- Claude Code의 스킬 명령은 플래그를 따로 해석하지 않고, 명령 뒤의 글을 통째로 스킬에 넘깁니다. 그래서 `--locale`은
  각 SKILL.md의 "Language" 절이 읽어서 처리하고, 스킬이 돌리는 스크립트에도 같은 값을 넘깁니다.
- 지금 어떤 언어로 판정되는지 확인:

```bash
python3 ~/.claude/skills/ig-i18n/ig_locale.py --text "회의록 정리"
```

| `/ig-viral --locale ko-KR 개발 생산성 계정에서 요즘 터지는 릴스` | 계정 중앙값 대비 배수로 순위, 한국어 공식으로 분류, 스와이프 파일 |
| `/ig-caption --locale ko-KR 위 릴스 캡션 써 줘. 검색어: 업무 자동화, 회의록` | 표시 폭 기준 첫 화면 미리보기와 한국어 캡션 검사 |

| `/ig-profile --locale ko-KR` (프로필 화면 붙여 넣기) | 12개 항목 100점 채점과 한국어 이름 칸, 소개 고치기 |
| `/ig-plan --locale ko-KR` | 한 주 계획(KST), 유형, 훅 공식, 소통 목록 |
| `/ig-human --locale ko-KR` (초안 붙여 넣기) | 안전한 자동 수정 + 확인할 표현 목록 + 다섯 가지 점검 |
| `/ig-comment --locale ko-KR` (남의 게시물 붙여 넣기) | 유형이 다른 댓글 후보 두 개 |
| `/ig-reply --locale ko-KR` (내 댓글 붙여 넣기) | 여섯 갈래 분류와 답글 |

| `/ig-repurpose --locale ko-KR` (영상 자막이나 글 붙여 넣기) | 한 주 분량의 릴스와 캐러셀 각도 |
| `/ig-audit --locale ko-KR` (인사이트 붙여 넣기, `1.2만` 표기 가능) | 배수, 3초 유지율, 공유율 기준 사후 분석 |

`voice.md`에 `Locale: ko-KR`을 넣었다면 `--locale ko-KR`은 생략해도 됩니다. 반대로 한국어가 기본인 사람이 영어 캡션이
필요하면 `/ig-caption --locale en-US ...`.

2,200자, 해시태그 5개, 피드 잘림 125는 Instagram이 정한(또는 추정한) 수치라 도구가 임의로 바꾸지 않습니다. 바뀌면
`--limit`, `--hashtag-limit`, `--truncate`나 `config.json`의 `platform`으로 바꾸세요. 한국어는 잘림을 글자 수가 아니라
표시 폭(한글과 이모지 2, 영문 1)으로 재고, 125는 한글 약 62자에 해당하는 추정치입니다(`--truncate-unit chars`로 글자 수 기준).

### AI 문체 다듬기

```bash
python3 humanize.py draft.txt --locale ko-KR -o clean.txt --report
python3 detect.py draft.txt clean.txt --locale ko-KR
```

보고서는 다섯 칸으로 나옵니다: 1 보이지 않는 문자(삭제), 2 문장부호(바꿈), 3 이중 피동(바꿈),
4 확인할 표현(자동 수정 안 함, 줄 번호와 제안), 5 구조 신호(자동 수정 안 함). 4와 5는 후보이지 판정이 아닙니다.
평범한 한국어(통해, 또한 한 번, 합니다체)는 걸리지 않게 했고, 반복을 세는 점검은 반복될 때만 걸립니다.
늘 쓰는 단어가 걸리면 `config.json`에 `"humanize_allow": ["강력한"]`처럼 넣으세요.

한국어는 자동 수정이 적어서 `humanize.py`만 돌려서는 점수가 거의 오르지 않습니다. 4번과 5번 목록대로 문장을
다시 쓰는 것이 이 스킬의 본 작업이고, `/ig-human`을 쓰면 Claude가 그 부분을 하고 의미가 바뀔 수 있는 문장은 확인을 받습니다.
테스트 데이터의 AI 문체 초안은 23.1점(의심)에서 다시 쓴 뒤 59.1점(검토)이 됩니다.

## 영어와 한국어의 동작 차이

| | en-US | ko-KR |
| --- | --- | --- |
| 훅 길이 | 단어 5~12개 | 말하는 음절 10~24개 |
| 구체성 | 숫자, 대문자 이름, 영어 수사 | 숫자와 한국어 단위, 고유어 수+단위(세 가지), 금액어, 영문 이름, 한글 브랜드 목록 |
| 긴장감 | 단어 목록 | 활용형 어간(잃었, 날렸, 망했) |
| 앞배치 | 부정어 포함 | 부정과 서술어는 문법상 끝이라 제외 |
| 대상 | you, 명령문 | 당신, 여러분, 존댓말 명령(~세요), 시청자에게 묻는 어미 |
| 치명적 문제 | 인사, 예고, stop scrolling, 해시태그, 이모지 | 같은 항목 + 과장 표현(충격, 역대급, 무조건) |
| 말 속도 | 165 WPM | 330 음절/분(추정) + 쉼, 보정 가능, 자막 읽기 검사 |
| 피드 잘림 | 125자 | 표시 폭 125(한글 약 62자) |
| 해시태그 | ASCII만(원작 그대로) | 한글 포함 |
| 다듬기 | 상투어 자동 치환 | 안전한 것만 자동, 나머지는 제안 |
| 문체 점검 VOICE | 축약형, 인칭 | 마지막 단어 다양성, 인칭과 구어, 구조 신호(합니다체 감점 없음) |

영어 쪽은 의도적으로 하나도 바꾸지 않았습니다. 예를 들어 영어 캡션의 한글 해시태그는 여전히 세지 않습니다(원작 동작).

## 테스트

```bash
cd instagram-agent-skill
python3 -m unittest discover -s tests -t tests
```

- `tests/golden/en/`: 원작 v1.0 코드로 만든 영어 출력 16가지(stdout, stderr, 종료 코드). 지금 코드가 한 글자라도 다르게
  출력하면 실패합니다. JSON에 새로 붙은 `locale` 키만 비교에서 뺍니다.
- 한국어 단위 테스트: 숫자 읽기, 음절과 쉼, 조사 떼기, 구체 표현, 표시 폭과 이모지.
- 한국어 훅: 점수 항목별 검사, 공식 분류(조정용 52문장 전부, 조정에 쓰지 않은 26문장 중 23문장 맞음, 오분류 0).
- 한국어 릴스 시간, 캡션, 다듬기와 탐지, 스와이프.
- 같은 장면을 영어와 한국어로 쓴 쌍을 비교하는 회귀 테스트(순위, 판정, 길이 비율).
- 언어 설정 우선순위와 기본값, 잘못된 값, 프로필과 글 언어 불일치 경고.
- 설치 호환성: 13개 스킬 그대로, 원작 SKILL.md 줄이 전부 그대로 남아 있는지, 스킬 하나만 복사했을 때 영어 출력이 원작과 같은지.

## 알려진 한계

- **점수는 휴리스틱입니다.** 한국어 훅 점수와 문체 점수의 기준값은 영어 패널의 의도를 옮긴 것이고, 한국어 릴스 성과나
  한국어 AI 탐지기 결과로 검증하지 않았습니다.
- **공식 분류 정확도는 직접 쓴 문장으로 잰 값입니다.** 실제 한국어 릴스 훅(구어, 맞춤법 오류, 자동 자막 띄어쓰기)에서는
  더 낮을 것입니다. 영어 원작은 실제 훅에서 49%를 분류했습니다.
- **말 속도는 추정입니다.** 기본 330음절/분과 쉼 길이는 측정값이 아닙니다. 보정 전 시간은 대략적인 계획용입니다.
  영어 단어를 한국어 음절로 바꾸는 계산도 근사입니다(Python은 3음절인데 2로 셉니다).
- **피드 잘림 위치는 추정입니다.** 기기, 글꼴, 줄바꿈에 따라 달라집니다.
- **한글 고유명사**는 `skills/ig-i18n/locales/ko-KR.json`의 `known_names` 목록에 있는 것만 이름으로 셉니다. 자주 쓰는
  이름은 목록에 추가하세요.
- 자동 수정은 이중 피동 정도뿐입니다. 의도된 설계지만, `humanize.py`만으로 점수가 오르길 기대하면 안 됩니다.
- 한국어 이외의 언어는 아직 없습니다. 추가 방법은 [docs/i18n.md](docs/i18n.md).
